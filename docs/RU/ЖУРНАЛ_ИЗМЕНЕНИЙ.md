# Журнал изменений

Все заметные изменения [WG Regions Studio](https://github.com/Serafim96/WG-Regions-Studio) фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

English version: [CHANGELOG.md](../EN/CHANGELOG.md)

## [2.0.5] — 2026-08-09

### Добавлено

- Рядом со справкой по флагу (**?**) в карточке региона / ведении флагов — кнопка-иконка «показать на схеме флага»; при несохранённых правках — короткое предупреждение сохранить сначала.
- На схеме флага справа сверху — бейдж **«Флаг: …»** (клик по имени — подогнать камеру; слева — справка и ведение флагов с фильтром).
- Легенда карты: вкладки **«Схема»** / **«Схема флага»** с образцами подписей узлов (◆ / ◇ / ∈ / ≈ и свечение текста).

### Изменено

- Затемнение на схеме флага — блёклые непрозрачные узлы вместо низкой opacity (рёбра не просвечивают).
- Spatial-рёбра на схеме флага: подсвеченные пересечения/вхождения — сплошные; dim-пересечения — блёклый пунктир; меньше дорогих комбинаций пунктир+прозрачность.
- Свечение текста (`text-outline`) только у регионов, где флаг задан (зелёное), и у участников конфликта (красное).
- Шире запас пана камеры вокруг схемы; диалог выбора флага всегда открывается с пустым полем.
- Сайдбар при старте развёрнут; пределы зума/пана включены.

## [2.0.2] — 2026-08-08

### Добавлено

- **Проверка обновлений** — при запуске сверка версии с последним релизом на GitHub; при устаревшей версии — toast и предупреждение в колокольчике со ссылкой на страницу релиза.

## [2.0.1] — 2026-08-08

### Добавлено

- **Очистить флаги** — жёлтая кнопка в карточке региона и в ведении флагов (выбранный регион), с подтверждением да/нет; очищает черновик, затем **«Сохранить»**.
- **Удалить все флаги** — красная кнопка в ведении флагов: снимает все флаги со всех регионов схемы, с подтверждением.
- Backend `DELETE /api/regions/flags` для очистки всех флагов регионов в сессии.
- **Уровень вложенности** — неизменяемое поле в карточке региона (как `d:` на схеме).

### Изменено

- **Ведение флагов** — убрана вкладка «дерево флага»; при фильтре по флагу рядом с регионом показывается значение, галка **«Наследование»** показывает унаследованные регионы.
- Подсветка флага: у унаследованных узлов светлый текст с обводкой — читается на цветной заливке (в т.ч. фиолетовой на уровне 2).

## [2.0.0] — 2026-08-08

### Добавлено

- **Открыть файл** — одна кнопка в сайдбаре открывает WorldGuard `regions.yml` / `.yaml` или сохранённую схему `.mrv.json`; из YAML схема строится сразу.
- **Экспорт YAML** — скачивание совместимого с WorldGuard `regions.export.yml` из текущей сессии, с вопросом про временные регионы и прокручиваемым диалогом ошибок (некорректные имена, циклы parent, неоднозначные конфликты флагов, нет координат).
- **Конфликты флагов** — анализ перезаписей по наследованию и пространственных пересечений; показ пар на схеме; неоднозначные случаи с равным приоритетом — ошибки в колокольчике уведомлений.
- **Колокольчик уведомлений** — ошибки и предупреждения (конфликты, сироты, перезаписи); клик по пункту фокусирует на схеме; иконка обновления в заголовке пересобирает список без toast.
- **Временные регионы** — черновики (включая потомков), правка геометрии/флагов/участников, переименование и удаление любого региона (каскад / переназначение родителя / сирота).
- **Ведение флагов** — редактор дерева, массовые операции, справочник; фильтр по флагу со значением и галкой наследования; кнопка флага на схеме — поиск + **Отобразить**; опции подсветки (пересечения / вхождения / наследование / конфликты) с метками ∈ / ≈ и значениями носителей.
- **Пересечения в карточке региона** — таблица частичных пересечений с **затронутыми блоками** и **процентом**, сортировка; в рёбрах хранится `overlapBlocks` после построения.
- **Инструменты схемы** — сброс схемы (убрать временные и пересобрать), очистка сессии, режимы рёбер, подсветка ветки / вхождения / пересечения, выравнивание раскладки, блокировка узлов.
- **UI** — тёмная/светлая тема, RU/EN, диалоги подтверждения в приложении (без браузерного `confirm()` для основных сценариев), зелёное сохранение / красное удаление, естественная сортировка в списках.

### Изменено

- Убран отдельный поток **Открыть YAML** / **Открыть схему** / **Построить схему** / **Отменить загрузку YAML** / **Перестроить схему**.
- Диалог выбора файла только с расширениями YAML и схемы (`excludeAcceptAllOption`); неверный или битый файл — диалог ошибки в приложении.
- Сайдбар больше не выводит счётчики узлов / авто-сворачивания в строку статуса (см. **Метрики**).
- Пустая схема: **Сохранить** и действия ниже неактивны, пока схема не загружена.
- Подписи вхождения в карточке сокращены до **Внутри** / **Содержит**; на схеме флага метка вхождения — **∈** (со значением контейнера) вместо ∉.
- Подсветка флага: понятнее задано vs унаследовано; парковка сирот и разведение пересечений в раскладке; в режиме «только конфликты» сохраняются нужные пути наследования.
- Кнопка сворачивания сайдбара остаётся слева сверху на схеме (рядом с добавлением временного региона), а не внутри панели.
- ПКМ по пустому месту схемы — меню добавления временного региона; при добавлении с узла родитель подставляется, но остаётся редактируемым.

### Документация

- README и двуязычные руководства в `docs/EN/` и `docs/RU/` обновлены под текущий UI.
