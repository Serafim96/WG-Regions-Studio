# Запуск юнит-тестов

Бэкенд-тесты лежат в `backend/tests/`. **Не нужны** Node.js и запущенный веб-сервер — только Python и пакеты из `requirements.txt`.

English version: [RUNNING_TESTS.md](../EN/RUNNING_TESTS.md)

## Подготовка

Один раз выполните **`setup.bat`** / **`setup.sh`** (или хотя бы создайте venv и `pip install -r requirements.txt`).

## Запуск всех тестов

Из корня репозитория (папка с `pytest.ini`, `backend/`, `frontend/`):

**Windows (PowerShell или CMD):**

```powershell
.\.venv\Scripts\activate
pytest
```

**Linux/macOS:**

```bash
source .venv/bin/activate
pytest
```

В `pytest.ini` уже указан каталог `backend/tests`.

## Опционально: точечный запуск

```bash
pytest backend/tests/test_parser.py
pytest backend/tests/test_full_dataset.py -v
```

Часть интеграционных тестов использует `backend/tests/fixtures/wg_regions_reference.yml`.

## Что покрыто

| Область | Примеры |
|---------|---------|
| YAML-парсер | `test_parser.py` |
| Дерево регионов | `test_tree.py` |
| Пространственная геометрия | `test_intersections.py` |
| I/O схемы | `test_scheme.py` |
| Полный экспорт | `test_full_dataset.py`, `test_reference_intersections.py` |
